# Менеджер паролей (CLI)

Консольное приложение для хранения паролей на Python. Данные хранятся в локальной базе SQLite3, пароли зашифрованы алгоритмом Fernet (симметричное шифрование из библиотеки `cryptography`), доступ защищён мастер-паролем.

## Возможности

- **Интерактивное меню** — при запуске без аргументов открывается меню с выбором действия (добавить / получить / список / удалить / сгенерировать / выход).
- **Мастер-пароль** — при первом запуске программа предлагает придумать мастер-пароль и сохраняет в базе его хеш SHA-256. При последующих запусках требуется ввод этого пароля (3 попытки на вход).
- **Шифрование паролей** — все пароли записей хранятся в базе только в зашифрованном виде (Fernet).
- **Генератор паролей** — криптографически стойкая генерация (`secrets`) с гарантией наличия букв разных регистров, цифр и спецсимволов.
- **Автоинициализация** — при старте автоматически создаются база данных, таблицы и файл ключа, если их ещё нет.

## Требования

- Python 3.10+
- Библиотека `cryptography`

## Установка

```bash
pip install -r requirements.txt
```

или просто:

```bash
pip install cryptography
```

## Запуск

```bash
python password_manager.py
```

При первом запуске программа попросит придумать мастер-пароль (минимум 8 символов) и повторить его. Этот пароль понадобится для входа при всех последующих запусках — **восстановить его невозможно**, без него доступ к записям не получить.

После входа открывается интерактивное меню:

```
+============================================+
|              Менеджер паролей              |
+============================================+
| 1) Добавить новый пароль                   |
| 2) Получить пароль                         |
| 3) Список всех паролей                     |
| 4) Удалить пароль                          |
| 5) Сгенерировать пароль                    |
| 6) Выход                                   |
+--------------------------------------------+
Выберите действие 1-6:
```

- Пункт **1** — добавление записи (название, логин, пароль скрытым вводом).
- Пункт **2** — получение пароля по названию записи.
- Пункт **3** — таблица всех записей (названия и логины).
- Пункт **4** — удаление записи с подтверждением.
- Пункт **5** — генератор: запросит длину (по умолчанию 16) и использование спецсимволов (по умолчанию да).
- Пункт **6** — выход.

После каждого действия программа возвращается в меню. Некорректный ввод (не число от 1 до 6) не завершает программу — выводится сообщение и меню показывается снова.

Те же действия доступны одной командой из терминала — запуск с аргументами пропускает меню: `python password_manager.py <команда> [аргументы]`.

## Команды (CLI)

### `add` — добавить новую запись

```bash
python password_manager.py add
```

Интерактивно запросит название/откуда (например, `Google`), логин и пароль (скрытым вводом, с повтором).

Доступны флаги, чтобы не вводить всё вручную:

```bash
# полностью вручную через флаги
python password_manager.py add -n GitHub -l ivanov -p "MySecret123"

# с автогенерацией пароля (длину можно задать флагом -L, по умолчанию 16)
python password_manager.py add -n GitHub -l ivanov -g
python password_manager.py add -n GitHub -l ivanov -g -L 24
```

| Флаг | Описание |
|------|----------|
| `-n, --name` | название/откуда (например, Google) |
| `-l, --login` | логин |
| `-p, --password` | пароль (иначе будет запрошен скрытым вводом) |
| `-g, --generate` | сгенерировать пароль вместо ввода |
| `-L, --length` | длина генерируемого пароля (по умолчанию 16) |

Название записи должно быть уникальным — запись с таким названием нельзя добавить дважды.

### `get` — получить пароль по названию

```bash
python password_manager.py get Google
```

Выведет название, логин и расшифрованный пароль. Пароль расшифровывается только после успешного входа мастер-паролем.

### `list` — список всех записей

```bash
python password_manager.py list
```

Показывает таблицу названий и логинов (пароли не выводятся).

### `delete` — удалить запись по названию

```bash
python password_manager.py delete Google
```

Запрашивает подтверждение (`y/n`). Флаг `-y / --yes` удаляет без подтверждения.

### `new` — сгенерировать новый пароль

```bash
python password_manager.py new            # пароль из 16 символов со спецсимволами
python password_manager.py new -l 20      # пароль из 20 символов
python password_manager.py new --no-symbols   # только буквы и цифры
```

| Флаг | Описание |
|------|----------|
| `-l, --length` | длина пароля (по умолчанию 16, минимум 8) |
| `--no-symbols` | не использовать специальные символы |

## Как это устроено

### Хранение данных

Всё хранится в SQLite3-базе `passwords.db`, которая создаётся рядом со скриптом при первом запуске. При старте программа проверяет наличие таблиц и создаёт их при необходимости.

Таблица `meta` — мастер-пароль:

| Поле | Описание |
|------|----------|
| `master_hash` | SHA-256 хеш мастер-пароля |

Таблица `entries` — записи:

| Поле | Описание |
|------|----------|
| `name` | название/откуда (уникальное, например `Google`) |
| `login` | логин |
| `password` | пароль **в зашифрованном виде** (токен Fernet, вида `gAAAAAB...`) |

### Шифрование

- Ключ шифрования хранится локально в файле `.key` рядом со скриптом. Если файла нет — при первом запуске генерируется новый (`Fernet.generate_key()`).
- Каждый пароль шифруется Fernet отдельным токеном и в базу записывается только шифротекст.
- Названия и логины хранятся в открытом виде — чтобы работал поиск и список записей без расшифровки.

### Структура файлов

```
password_manager.py   # код приложения
requirements.txt      # зависимости
passwords.db          # база данных (создаётся автоматически)
.key                  # ключ шифрования (создаётся автоматически)
```

> **Важно:** потеря файла `.key` делает расшифровку сохранённых паролей невозможной. Не удаляйте и не перезаписывайте его. Перенос базы на другой компьютер требует переноса и `.key`, и `passwords.db` вместе.

### Структура кода

- функции шифрования: `load_or_create_key`, `encrypt_password`, `decrypt_password`
- функции БД: `connect`, `init_db`, `set_master_password`, `verify_master_password`, `add_entry`, `get_entry`, `list_entries`, `delete_entry`
- генератор: `generate_password`
- интерактивное меню: `print_menu`, `run_menu_action`, `interactive_menu`, `prompt_length`, `confirm`
- CLI-обработчик: `authenticate`, `cmd_add`, `cmd_get`, `cmd_list`, `cmd_delete`, `cmd_new`, `build_parser`, `main`

## Безопасность и ограничения

- Мастер-пароль хранится как SHA-256 без соли (в соответствии с требованиями задачи). Для продакшена лучше использовать PBKDF2/argon2.
- Файл `.key` лежит в открытом виде рядом с базой: любой, кто получит доступ к папке (и к вашей учётной записи), сможет расшифровать пароли. Для дополнительной защиты храните папку на зашифрованном диске.
- Названия и логины не шифруются.
- При попытке расшифровки «чужим» ключом (например, базу перенесли без своего `.key`) программа сообщит об ошибке расшифровки.
